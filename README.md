# Restaurant Waiters App

This is a Flutter-based mobile application designed to assist **restaurant waitstaff** with managing orders, tables, and customer interactions more efficiently.

---

## 🔧 Base Setup Included in This Milestone

This milestone includes the setup of **core UI components**, **app-wide theming**, and **base architecture** structure to ensure maintainable, scalable development moving forward.

---

## 📁 `components/` – Reusable UI Widgets

This folder contains reusable and customizable UI components that follow the app’s design guidelines:

### 🔹 `app_bottom_sheet.dart`
Reusable widget for showing bottom sheets with consistent design across the app.

### 🔹 `app_button.dart`
Custom button widget that supports different styles, sizes.

### 🔹 `app_switch.dart`
Themed switch component, used for toggling light and dark mode.

### 🔹 `app_text.dart`
Centralized text widget to enforce consistent font styles and weights throughout the app.

### 🔹 `no_data_found.dart`
A widget used to display a message or illustration when there is no data available (e.g., empty list views).

### 🔹 `receipt_clipper.dart`
Custom clipper to provide a receipt-style visual effect for widgets like bills or order slips.

### 🔹 `segmented_tabbar.dart`
A segmented control (tabbar) widget for navigating between different app sections.

---

## 📁 Other Relevant Directories

- `theme/` – App-wide light/dark theme setup
- `routes/` – Centralized route management
- `utils/constants/` – Color, string, and constant definitions
- `modules/home/` – Example module structure using GetX (`bindings`, `controllers`, `views`)
- `gen/` – Auto-generated asset and font references
